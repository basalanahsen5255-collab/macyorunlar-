# Maç Yorumları Uygulaması ⚽

Bu proje, futbol maçları hakkında kullanıcıların yorum yapabileceği ve güncel yorumları takip edebileceği bir Android uygulamasıdır.

## 🚀 Özellikler
* **Maç Listeleme:** Güncel maçları görüntüleme.
* **Yorum Yapma:** Maçlar hakkında detaylı yorum bırakma.
* **Detay Sayfası:** Her maç için yapılan yorumların ayrıntılı incelenmesi.

## 🛠 Kullanılan Teknolojiler
* **Dil:** Java / Kotlin
* **IDE:** Android Studio
* **Build System:** Gradle (KTS)
* **UI:** XML Layouts
